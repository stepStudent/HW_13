# Завдання 3: Інтерактивний каталог студентів (React + Vite)

Розширення застосунку із **Завдання 2** відповідно до вимог домашньої роботи IT STEP Academy.

---

## 🎯 Реалізовані вимоги

1. **Кнопка «Показати / приховати студентів» через `useState`**:
   * Стан видимості керується хуком `useState(true)`.
   * При натисканні на кнопку статус перемикається:
     * Коли активний (`true`): відображається текст «Приховати студентів» (👁️) та повний каталог карток.
     * Коли вимкнений (`false`): відображається «Показати студентів» (👁️‍🗨️), список карток ховається, а замість нього з'являється інформативне повідомлення з можливістю відкрити каталог одним кліком.

2. **Фільтр студентів за курсом навчання**:
   * Стан обраного курсу зберігається через `useState('all')`.
   * Реалізовано інтерактивні кнопки-чіпси для швидкого вибору:
     * «Всі курси»
     * «1 курс», «2 курс», «3 курс», «4 курс», «5 курс»
   * На кожній кнопці відображається бейдж із кількістю студентів на цьому курсі.
   * Додатково додано випадаючий список `<select>` для швидкої фільтрації та зручності на мобільних пристроях.
   * Кнопка «✕ Скинути фільтр» дозволяє миттєво повернутися до показу всіх курсів.

3. **Лічильник кількості студентів, які зараз відображаються на сторінці**:
   * Динамічний підрахунок кількості студентів, які фактично відображені в даний момент:
     * Якщо картки приховані перемикачем — лічильник показує `0`.
     * Якщо активна фільтрація за курсом — відображається кількість знайдених студентів (наприклад, `2 з 9`).
   * Окремий статусний бейдж та блок статистики зі світловим пульсуючим індикатором активності.

4. **Збережено базовий функціонал із Завдання 2**:
   * `StudentCard.jsx`: передача через `props` імені, віку, курсу, спеціальності та аватара.
   * `Counter.jsx`: компонент обліку відвідувань занять через `useState` з кнопками збільшення (`+1`) та скидання (`🔄 Скинути`).

## 🛠️ Запуск та збірка проєкту

### 1. Перехід у робочу папку
```bash
cd Task_3
```

### 2. Встановлення залежностей (якщо необхідно)
```bash
npm install
```

npm run dev
