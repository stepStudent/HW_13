# Завдання 1: Генератор випадкових фактів 🧠✨

Вебзастосунок у легкому гумористичному стилі, який отримує випадкові цікаві факти із зовнішнього REST API та надає можливість переглядати їх як в оригіналі (англійською), так і в автоматичному перекладі українською мовою.

---

## 📋 Опис проєкту

Проєкт реалізовано в межах домашнього завдання без використання сторонніх фреймворків (чистий Vanilla JS, семантичний HTML5 та сучасний CSS3).

### Основні можливості:
* 🎲 **Отримання фактів:** звернення до зовнішнього API через `fetch()` та `async/await`.
* 🇺🇦 **Підтримка перекладу:** інтеграція з API перекладу (MyMemory API) для відображення факту солов'їною мовою з можливістю перемикання режимів (`🇺🇦 Укр`, `🇬🇧 Eng`, `🌐 Обидва`).
* ⏳ **Стан завантаження:** плавний спінер із текстом «Завантаження...» та змінними кумедними фразами під час очікування відповіді.
* 🛡️ **Обробка помилок:** перевірка кодів відповідей сервера (`response.ok`), таймаути запитів та зрозуміле людині повідомлення про помилку з кнопкою швидкого повтору «Спробувати ще раз 🔄».
* 📋 **Копіювання:** кнопка копіювання поточного тексту факту в буфер обміну.
* 🎨 **Гумористичний дизайн:** плаваючі емодзі на фоні, неоморфно-скляна картка (glassmorphism), градієнти та плавна анімація кнопок.

---

## 🛠️ Стек технологій

* **HTML5** — доступна та семантична розмітка
* **CSS3** — адаптивна верстка, Flexbox, CSS Grid, анімації, змінні (CSS Variables)
* **JavaScript (ES6+)** — `fetch()`, `async/await`, `AbortController` (таймаути), Clipboard API
* **API:**
  * Отримання фактів: [Useless Facts API](https://uselessfacts.jsph.pl/api/v2/facts/random?language=en)
  * Переклад: [MyMemory Translation API](https://api.mymemory.translated.net/)

## 🚀 Як запустити проєкт

Проєкт є статичним вебсайтом, тому для його запуску не потрібна попередня інсталяція пакетів:

### Варіант 1: Прямий запуск у браузері (найпростіший)
Двічі клацніть по файлу `index.html` або перетягніть його у будь-який сучасний браузер (Google Chrome, Firefox, Safari, Edge).

### Варіант 2: Через розширення Live Server у VS Code (рекомендований)
1. Відкрийте папку `Task_1` у редакторі VS Code.
2. Клацніть правою кнопкою миші на файл `index.html`.
3. Оберіть **«Open with Live Server»**.

### Варіант 3: Через термінал (локальний вебсервер)
Якщо у вас встановлений Python або Node.js:

* **З Python:**
  ```bash
  cd Task_1
  python3 -m http.server 8080
  ```
  Після цього відкрийте в браузері: `http://localhost:8080`

* **З Node.js (npx):**
  ```bash
  cd Task_1
  npx serve .
  ```
