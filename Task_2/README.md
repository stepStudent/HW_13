# Завдання 2: React — Каталог студентів

React-застосунок, розроблений за допомогою **Vite**, який демонструє роботу з компонентами, передачу даних через `props` та використання хука `useState` для лічильника відвідувань.

---

## 📁 Структура проєкту

```text
Task_2/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── App.css
    ├── App.jsx
    ├── index.css
    ├── main.jsx
    └── components/
        ├── Counter.css
        ├── Counter.jsx
        ├── StudentCard.css
        └── StudentCard.jsx
```

---

## 🚀 Виконані вимоги

1. **Ініціалізація:** Створено проєкт на базі React 18 + Vite.
2. **Компонент `StudentCard.jsx`:**
   * Приймає через `props`: ім'я (`name`), вік (`age`) та курс навчання (`course`).
   * Додатково додано напрямок навчання та візуальний аватар.
3. **Картки студентів:** Відображено 5 карток студентів (вимога: щонайменше 4).
4. **Компонент `Counter.jsx`:**
   * Підраховує кількість відвідувань занять за натисканням кнопки `➕ Зареєструвати присутність (+1)`.
   * Стан зберігається за допомогою `useState()`.
   * Кнопка `🔄 Скинути` повертає значення лічильника до нуля (деактивується, коли значення 0).
5. **Стилізація:** Сучасний адаптивний CSS з акцентними кольорами, картками, бейджами та ефектами наведення.

---

## 🛠️ Запуск проєкту

1. Перейдіть до папки завдання:
   ```bash
   cd Task_2
   ```

2. Встановіть залежності (якщо не встановлені):
   ```bash
   npm install
   ```

3. Запустіть локальний сервер розробки:
   ```bash
   npm run dev
   ```

4. Збірка для продакшну:
   ```bash
   npm run build
   ```
