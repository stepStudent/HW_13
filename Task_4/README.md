# Завдання 4. React — Інтерактивний список улюблених фільмів (Movie Watchlist)

React-застосунок для керування власним списком фільмів до перегляду з можливістю додавання фільмів, перемикання статусу «Переглянуто», підрахунком статистики та збереженням у `localStorage`.

---

## 📋 Виконання функціональних вимог

| № | Вимога | Реалізація |
|---|---|---|
| **1** | Створити компонент `MovieCard.jsx`, який відображає назву фільму, жанр та статус перегляду | `src/components/MovieCard.jsx` відображає заголовок фільму, бейдж жанру та бейдж зі статусом «Переглянуто» / «Не переглянуто» |
| **2** | Передавати інформацію про фільм через `props` | Дані фільму (`id`, `title`, `genre`, `isWatched`) та обробники дій передаються до `MovieCard` через `props` |
| **3** | Створити компонент `MovieList.jsx`, який відображає всі фільми | `src/components/MovieList.jsx` ітерується по масиву фільмів та рендерить відповідні `MovieCard` з підтримкою empty state |
| **4** | Додати форму для введення назви та жанру нового фільму | `src/components/MovieForm.jsx` містить текстові поля з валідацією та швидким вибором популярних жанрів (`datalist`) |
| **5** | Реалізувати додавання фільмів за допомогою `useState` | Стан форми контролюється через `useState` в `MovieForm`, а загальний список фільмів оновлюється через `setMovies` в `App.jsx` |
| **6** | Додати кнопку «Переглянуто», яка змінює статус фільму | Кнопка «Переглянуто» в `MovieCard` викликає функцію `onToggleWatch(id)` для інверсії статусу `isWatched` |
| **7** | Відображати кількість переглянутих і непереглянутих фільмів | Компонент `MovieStats.jsx` обчислює та динамічно показує лічильники «Всього», «До перегляду», «Переглянуто» та прогрес-бар |
| **+** | **Додаткове ускладнення**: збереження списку в `localStorage` | Використано збереження у `localStorage` (`movie_watchlist_data_v1`): стан ініціалізується збереженими даними, а `useEffect` синхронізує зміни |

---

## 🚀 Додаткові покращення та можливості

- **Фільтрація та таби**: швидкий перемикач «Всі», «🍿 До перегляду», «✅ Переглянуті».
- **Пошук у реальному часі**: швидкий пошук за назвою або жанром фільму.
- **Фільтр за жанрами**: динамічний випадаючий список унікальних жанрів із поточної колекції.
- **Видалення та скидання**: можливість видалити окремий фільм, скинути список до початкових фільмів або повністю очистити список.
- **Сучасний адаптивний UI**: естетичний темний кінематографічний дизайн із підтримкою мобільних пристроїв, плавною анімацією та фокусуванням.
